05 My working process

How I work with
Claude Code and Codex.

A scoped brief, a supervised implementation and a review loop — with me setting priorities, validating the work and making the final release decision.

  1. 01

    Claude Code supervises

    I use Claude Code to shape the plan, break work into tasks, delegate implementation to Codex and review the returned changes against the brief.

  2. 02

    Codex implements

    Codex works through the scoped implementation, updates the code, runs relevant checks and revises the changes as review feedback comes back.

  3. 03

    I own the outcome

    I set priorities and constraints, review the code and behavior, validate the result with the team and decide what is ready to merge or release.
